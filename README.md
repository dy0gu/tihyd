# The endgame you've been waiting for! 🕰️⚰️

TIHYD (/taɪd/) is a mod that focuses on adding fully configurable character aging functionality to Project Zomboid.

## Installation 🛠️

- Clone the repository:

  ```shell
  git clone https://github.com/dy0gu/tihyd.git
  ```

- Copy `src/Contents/mods/TIHYD` into your `~/Zomboid/mods/` folder.

## Usage ▶️

- Launch the game and activate the mod in the respective panel.
- Choose your starting age on the character appearance screen and configure aging in the sandbox options.
